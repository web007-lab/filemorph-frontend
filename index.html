Accurate Binary-Search Image Optimization

Most standard image converters reduce resolution linearly, which leads to unpredictable file sizes. FileMorph utilizes a multi-pass binary search algorithm that balances pixel dimensions and quantization tables to lock down file sizes just below your target constraint (1KB to 300KB) without unnecessary visual degradation.
